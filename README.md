# 💕 Kukulana Day — Kalenda ya Intimacy PWA

Programu ya kalenda ya karibu kwa wapendanao, iliyoandikwa kwa Kiswahili.

## Jinsi ya Kuanzisha kwenye GitHub Pages

### Hatua 1 — Pakia kwenye GitHub
```bash
git init
git add .
git commit -m "💕 Kukulana Day — first commit"
git branch -M main
git remote add origin https://github.com/JINA_LAKO/kukulana-day.git
git push -u origin main
```

### Hatua 2 — Washa GitHub Pages
1. Nenda Settings → Pages
2. Source: **GitHub Actions**
3. Bonyeza Save

### Hatua 3 — GitHub Action itafanya kazi yenyewe
Baada ya push, GitHub Action itafanya deploy moja kwa moja.
URL yako: `https://JINA_LAKO.github.io/kukulana-day`

## Vipengele / Features
- 📅 Kalenda ya kila mwezi — inaonyesha siku za upendo (Jumatatu, Jumatano, Jumamosi, siku ya mwisho ya mwezi)

- 📱 PWA — inaweza kusanikishwa kwenye simu kama programu
